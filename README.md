# ConnectX - The Only service that you need , to connect across all layers of organization

This is an extension that was developed as a part of hackathon that involves the automation of tasks in an organisation where in the call is recorded and at the end of the call , a transcribe will be taken and the head allows up the follow-ups , sets up stuffs as needed . Also , we created an AI assisted voice automed AI agent which will talk back to the client as required .
