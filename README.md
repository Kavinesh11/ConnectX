# ConnectX

This project aims to automate redunant tasks in industry , where in we created a chrome extension for recording the video with captions using python , then parse that up and do Digital Image Processing over here where in the last frame of a second is being taken and processed using gemini and llama models . Also , implemented is the call service using local number in twilio which connects us to the client or an employer and gives prior information to them .
